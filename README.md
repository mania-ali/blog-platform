# 📝 Scribble - Full-Stack Blog Platform

A full-stack blogging application where users can register, log in, write posts, and view a global feed.

🚀 **Live Demo:** [https://your-app-name.vercel.app](https://your-app-name.vercel.app)

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS (Hosted on **Vercel**)
- **Backend:** Node.js, Express, Prisma ORM (Hosted on **Railway**)
- **Database:** PostgreSQL (Hosted on **Railway**)
- **Authentication:** JWT (JSON Web Tokens) & bcrypt

---

## 📁 Project Structure

- [`/frontend`](./frontend) - React single-page application
- [`/backend`](./backend) - REST API server & database schema

---

## ✨ Key Features

- 🔐 User Authentication (Register & Login with JWT)
- 📰 Global News Feed
- 📊 Personal Dashboard & Analytics (User's own posts)
- ✍️ Post Management (Create, Edit, Delete posts)
